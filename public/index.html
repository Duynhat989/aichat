AI Chat

API phục vụ chat đa phương tiện, kiểm tra chính tả, tóm tắt, dịch và hướng dẫn học tập.

  • POST /api/ai-chat — prompt + file (≤5MB) + ảnh (≤10MB)
  • POST /api/spell-check — JSON text
  • POST /api/summarize — JSON text
  • POST /api/translate — JSON text, sourceLanguage, targetLanguage
  • POST /api/study-guide — subject, câu hỏi / file / ảnh
